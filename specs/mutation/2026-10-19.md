**Plan:** `specs/atelier-unit/plan.md`, Tasks 3 and 4 (framework-tests F6), and the fix pass of the feature review, `specs/atelier-unit/review.md`. The baseline is report-only, and no test changed because of it. Tests changed in the prune and the fix pass, as recorded below.

## Correction: the first zip baseline was false

This branch's first baseline (b2a4c74) showed 8 survivors. The real number is 22, as the feature review found (C1).
- **The cause:** Infection's include interceptor answers a stat on an unreadable path with false (`vendor/infection/include-interceptor/src/IncludeInterceptor.php:385`). So `KitArchiveBuilderTest::test_an_unreadable_file_is_skipped_and_reported` failed in every mutant process. Infection runs a covering test's file and stops at its first failure. Every KitArchiveBuilder and ArchiveNameSanitizer mutant that test file covered therefore counted as killed, whatever the mutant changed.
- **The fix:** that test is in the `no-mutation` group, which `infection.json5` excludes (`"testFrameworkExtraArgs": "--exclude-group=no-mutation"`). Plain PHPUnit still runs it in the gate.
- **The proof, under the interceptor:** PHPUnit with every source file intercepted unchanged fails that one test (`Tests: 94, Failures: 1`), and with the group excluded it passes (`OK (93 tests)`).
- **The proof, through Infection:** `--noop`, where every mutant changes nothing. Without the exclusion, 117 of 186 no-op mutants counted as killed (45 in the sanitizer, 72 in the builder). With it, 0 do.
- **The cost:** `KitArchiveBuilder.php:85`, the `continue` after "cannot be read", is reached only by the excluded test, so it now shows as not covered.

A run that writes no log therefore fails instead of passing on a stale one.
- **Tools:** Infection 0.35.8, PCOV coverage on PHP 8.3.6, and PHPUnit 10.5.66.
- **Config:** `infection.json5`.
  - The timeout is 20 s per mutant, so that a busy shared box does not create timeouts.
  - `bootstrap` is `tests/bootstrap.php`. Without it, Infection's process autoloads a source class with no `ABSPATH` defined, the file's guard runs a bare `exit`, and the run stops silently with status 0 before it generates any mutant.
  - The `no-mutation` group is excluded (see the correction).
- **The baseline:** the Task 3 tests (both files as at b2a4c74, 117 tests), with the exclusion. It took 14 s.
