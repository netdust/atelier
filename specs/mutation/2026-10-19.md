# Mutation baseline — the card and the zip (2026-10-19)

**Plan:** `specs/atelier-unit/plan.md`, Task 3 (framework-tests F6). Report-only: no test was changed because of it.

## The run

- **Command:** `composer mutation`, which runs `infection services/card/VCardBuilder.php services/presskit/KitArchiveBuilder.php services/presskit/ArchiveNameSanitizer.php --with-uncovered --threads=4 --log-verbosity=all`.
- **Tools:** Infection 0.35.8, PCOV coverage on PHP 8.3.6, and PHPUnit 10.5.66. The suite is atelier's unit tier, 117 tests.
- **Config:** `infection.json5`.
  - The timeout is 20 s per mutant, so that a busy shared box does not create timeouts.
  - `bootstrap` is `tests/bootstrap.php`. Without it, Infection's own process autoloads a source class with no `ABSPATH` defined. The file's guard then runs a bare `exit`, and the run stops silently with status 0 before it generates any mutant.
- **Time:** 12 s.
